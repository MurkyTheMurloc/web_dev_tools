# web_dev_tools

Bun workspace for the `@murky-web` package family.

## Packages

- [`@murky-web/typebuddy`](packages/typebuddy): runtime guards, `Result`, utility and global types, oxlint plugin
- [`@murky-web/simplelog`](packages/simplelog): small logger, oxlint plugin
- [`@murky-web/oxlint-plugin-solid`](packages/oxlint-plugin-solid): Solid rules for oxlint
- [`@murky-web/shadcn-lint`](packages/shadcn-lint): Tailwind design-system rules for Solid 2.0

Shared oxlint, oxfmt and tsconfig settings live in [`config/`](config).
